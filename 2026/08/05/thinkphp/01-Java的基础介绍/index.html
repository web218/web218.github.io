Java的基础介绍

1.Java的基础介绍

1.Java属于混合型语言，既属于编译型又属于解释型

  1. 编译阶段（javac）：.java → .class（字节码）。这一步是编译，但编译目标不是机器码，是 JVM 能读的中间指令（字节码）。这也是跨平台的来源——只要装了对应 JVM。
  2. 运行阶段（JVM）：
  • 解释器：逐条把字节码翻译成机器码执行（慢）。
  • JIT 编译器（即时编译）：热点代码在运行时编译成机器码缓存（快）。
  • 所以运行时既解释又编译，现代 JVM 主要是 JIT 在干活。

Java可在多个平台上运行

  • 手机app（安卓Java）

  • MineCraft （JAVA版本）

    等等

2.JDK和JRE的区别

1.JRE ：只有java的运行环境

2.JDK：有Java的开发环境，包含JRE 二者属于包含与被包含关系

如果需要运行JAVA程序只要安装JRE ，如果开发的话则需要jdk
